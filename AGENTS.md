## Project: PlusThreeEightZero

Static agency website. Astro + Tailwind CSS v4. Bilingual: English + Ukrainian.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Build

```
npm run build
```

Output goes to `dist/` (this folder is gitignored and never edited manually).

## File Structure

```
plusthreeeightzero/
├── .github/workflows/deploy.yml   ← GitHub Actions (auto-deploy on push to main)
├── public/                        ← static files (images, favicon) — copied as-is to dist/
├── src/
│   ├── pages/
│   │   ├── index.astro            ← redirects to /en/
│   │   ├── en/                    ← English pages
│   │   └── uk/                    ← Ukrainian pages
│   ├── layouts/
│   │   └── BaseLayout.astro       ← main HTML layout
│   ├── components/
│   │   ├── Header.astro
│   │   ├── Footer.astro
│   │   └── LanguageSwitcher.astro
│   └── styles/
│       └── global.css             ← Tailwind import + custom theme
├── astro.config.mjs               ← Astro config (Tailwind plugin + i18n)
├── package.json
└── dist/                          ← generated build output (NEVER edit manually)
```

## Rules

- All UI text must exist in both languages (en + uk)
- English is the default language
- Pages live in `src/pages/en/` and `src/pages/uk/`
- Components go in `src/components/`
- Static assets (images, favicon) go in `public/`
- Do NOT edit `dist/` — it is generated by `npm run build`
- Do NOT edit `node_modules/`
- Styles use Tailwind v4 utility classes — no SCSS
- Layout uses `BaseLayout.astro` — all pages must wrap content in it
- Header and Footer are included on every page
